# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The SatyaCheck team takes security seriously. If you discover a security vulnerability or sensitive data leakage within this repository:

1. **Do not create a public issue.**
2. Report the vulnerability privately by opening a [Security Advisory](https://github.com/shivamrana200526-beep/Fake-News-Detection-System/security/advisories) on GitHub or contacting the maintainers directly.
3. Include detailed steps to reproduce the vulnerability, including attack vectors and potential impact.

We will acknowledge your advisory within 48 hours and work with you to resolve the issue responsibly before any public disclosure.
