1. Executive Summary & Scope

The Frontend Developer is responsible for the entire user-facing surface of the SatyaCheck platform. The mission of this role is to translate complex, 10-dimensional artificial intelligence forensic fact-checking data into an intuitive, accessible, and editorial visual experience. The user interface eliminates cognitive overload and empowers citizens, researchers, and journalists to verify viral claims in seconds.

Core Engineering Objectives:
  • Deliver sub-100ms client route transitions via client-side routing (wouter).
  • Provide 4 distinct input verification modes: Raw Text, Web Article URL, Headline, and Screenshot Image.
  • Render dynamic, accessible forensic breakdown cards with Recharts visualization graphs.
  • Enable private, offline-first client storage via browser localStorage with instant CSV export.
  • Support accessibility: Web Speech API microphone dictation, keyboard shortcuts (Ctrl+Enter), and persistent light/dark themes.

4. Core Code Implementations

4.1 API Integration Hook (src/hooks/use-analysis.js)

This custom hook utilizes TanStack Query's useMutation to dispatch verification requests to the Express backend and automatically invalidate platform statistics caches: 

import { useMutation, useQuery, useQueryClient } from "@tanstack/react-query";

// Dispatches content (text, URL, or image base64) to the backend API
export function useAnalyzeContent() {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: async ({ content, type }) => {
      const res = await fetch("/api/analyze", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ content, type }),
      });
      if (!res.ok) {
        const err = await res.json().catch(() => ({}));
        throw new Error(err.message || "Failed to analyze content");
      }
      return res.json();
    },
    onSuccess: () => {
      // Invalidate global stats and history queries so UI re-fetches automatically
      queryClient.invalidateQueries({ queryKey: ["/api/stats"] });
      queryClient.invalidateQueries({ queryKey: ["/api/history"] });
    },
  });
}

// Fetches global platform analytics for the dashboard
export function useStats() {
  return useQuery({
    queryKey: ["/api/stats"],
    queryFn: async () => {
      const res = await fetch("/api/stats");
      if (!res.ok) throw new Error("Failed to load statistics");
      return res.json();
    },
    staleTime: 1000 * 60 * 5, // 5 minutes cache
  });
}

4.2 Web Speech API Voice Dictation Hook (src/hooks/use-voice-input.js)

import { useState, useCallback } from "react";

export function useVoiceInput(onResult) {
  const [isListening, setIsListening] = useState(false);
  const [error, setError] = useState(null);

  const startListening = useCallback(() => {
    const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;
    if (!SpeechRecognition) {
      setError("Speech recognition is not supported in this browser.");
      return;
    }
    const recognition = new SpeechRecognition();
    recognition.continuous = false;
    recognition.interimResults = false;
    recognition.lang = "en-US";

    recognition.onstart = () => { setIsListening(true); setError(null); };
    recognition.onresult = (event) => {
      const transcript = event.results[0][0].transcript;
      onResult(transcript);
    };
    recognition.onerror = (e) => { setError(e.error); setIsListening(false); };
    recognition.onend = () => setIsListening(false);

    recognition.start();
  }, [onResult]);

  return { isListening, error, startListening };
}

4.3 Client-Side Storage & CSV Export (src/pages/History.jsx)

const STORAGE_KEY = "satyacheck_history";

export function saveToHistory(entry) {
  try {
    const existing = JSON.parse(localStorage.getItem(STORAGE_KEY) || "[]");
    const newEntry = {
      ...entry,
      id: Date.now().toString(),
      timestamp: new Date().toISOString(),
    };
    const updated = [newEntry, ...existing].slice(0, 100); // Cap at 100 entries
    localStorage.setItem(STORAGE_KEY, JSON.stringify(updated));
    return updated;
  } catch {
    return [];
  }
}

export function exportHistoryToCSV(entries) {
  const headers = ["Date", "Type", "Content", "Verdict", "Confidence"];
  const rows = entries.map(e => [
    e.timestamp,
    e.type,
    `"${(e.content || "").replace(/"/g, '""')}"`,
    e.verdict,
    `${e.confidence}%`
  ]);
  const csvContent = "data:text/csv;charset=utf-8," + [headers, ...rows].map(r => r.join(",")).join("\n");
  const encodedUri = encodeURI(csvContent);
  const link = document.createElement("a");
  link.setAttribute("href", encodedUri);
  link.setAttribute("download", `satyacheck_history_${new Date().toISOString().slice(0,10)}.csv`);
  document.body.appendChild(link);
  link.click();
  document.body.removeChild(link);
}

7. Viva & Technical Defense Q&A

Q1: Why did you choose React 19 with Vite instead of Next.js?
A: SatyaCheck is designed as an ultra-fast client-side single page application (SPA). Vite 7 provides instant hot-module replacement (sub-50ms) and outputs lightweight static bundles that can be deployed to any CDN or static server without server-rendering overhead.
Q2: How does the client prevent UI freezing during long AI inferences?
A: All network calls are managed asynchronously using TanStack React Query. The UI displays responsive skeleton loaders and animated progress bars, ensuring the browser main thread remains completely interactive.
Q3: How is user privacy guaranteed on the frontend?
A: History records are stored exclusively in the user's browser localStorage. No search history or tracking cookies are sent to third-party ad networks.
