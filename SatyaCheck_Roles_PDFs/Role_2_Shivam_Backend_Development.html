1. Executive Summary & Role Scope

As the Backend Development Lead (Shivam), my responsibility encompasses the server infrastructure, HTTP request lifecycles, route aggregation, authentication security, web content extraction, and deployment wrappers for the SatyaCheck platform.

The backend is built as a pure JavaScript ES Module (ESM) application running on Node.js 20+ and Express 5. It manages request handling, password hashing via scryptSync, timing-safe credential verification via timingSafeEqual, session management, structured logging with header redaction, and HTML web scraping for article analysis.

2. Complete Backend Architecture & Request Flow

The backend follows a clean, modular pipeline from request to response:

} function extractMeta(html, property) { const patterns = [ new RegExp(`]+property=["']${property}["'][^>]+content=["']([^"']+)["']`, "i"), new RegExp(`]+content=["']([^"']+)["'][^>]+property=["']${property}["']`, "i"), new RegExp(`]+name=["']${property}["'][^>]+content=["']([^"']+)["']`, "i"), new RegExp(`]+content=["']([^"']+)["'][^>]+name=["']${property}["']`, "i"), ];
